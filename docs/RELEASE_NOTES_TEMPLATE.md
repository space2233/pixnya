# PixNya stable Release notes template

正式版 Release 说明保持简短，只列用户可见变化和支持平台。连接风险、源码、许可证、SBOM、校验和及升级验证细节统一放在项目主页与 Release 的验证包中。

发布前替换版本号和变更列表；不得保留 `PENDING` 或模板占位符。

```markdown
# PixNya {{version}}

## 中文

- {{主要新增功能}}
- {{重要体验优化或修复}}
- 支持 Windows x64/ARM64、Linux x64、Android ARM64/ARM32（Android 10+）。

## English

- {{Main new features}}
- {{Important improvements or fixes}}
- Supports Windows x64/ARM64, Linux x64, and Android ARM64/ARM32 (Android 10+).
```
