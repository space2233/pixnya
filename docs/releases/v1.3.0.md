# PixNya 1.3.0

## 中文

- 新增 Windows ARM64 原生应用与 Android ARM32 独立安装包。
- 自动更新会按 Windows 架构或 Android ABI 选择正确产物。
- 支持 Windows x64/ARM64、Linux x64、Android ARM64/ARM32（Android 10+）。

## English

- Added a native Windows ARM64 app and a separate Android ARM32 package.
- Automatic updates now select the correct Windows architecture or Android ABI.
- Supports Windows x64/ARM64, Linux x64, and Android ARM64/ARM32 (Android 10+).
