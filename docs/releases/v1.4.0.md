# PixNya 1.4.0

## 中文

- 新增本地数据备份与迁移，可选择包含离线资料，并支持合并或替换恢复。
- 插画与小说收藏新增官方标签筛选和批量管理，可批量修改公开性、添加或移除标签、取消收藏。
- 备份不包含登录令牌、Cookie、连接模式或其他凭据；恢复前会校验文件完整性，失败时自动回滚。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Added local data backup and transfer, with optional offline content and merge or replace restore modes.
- Added official tag filters and batch management for illustration and novel bookmarks, including visibility, tags, and removal.
- Backups exclude login tokens, cookies, connection modes, and other credentials. Restore validates integrity and rolls back on failure.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
