# PixNya 1.6.3

## 中文

- 小说阅读改为全屏沉浸分页：点中间显示工具栏，左右滑动、点边缘或可选的音量键翻页，可调字号、行距和夜间模式。
- 修复分页漏字、页码挡住最后一行与长文卡顿；正文加载失败时自动重试最多 3 次。
- 列表划到底自动加载下一页；设置页与阅读页返回按钮为胶囊形状。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Full-screen paginated novel reader: tap the center for chrome; swipe, tap the edges, or optionally use the volume keys to turn pages; adjust type size, line height, and night mode.
- Stops leaked page text and page numbers covering the last line, retries a failed novel-body load up to 3 times, and keeps only the current page mounted so long novels stay responsive.
- Feeds load the next page when you reach the bottom; capsule-shaped back controls on settings and reader screens.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
