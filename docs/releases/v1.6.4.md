# PixNya 1.6.4

## 中文

- 小说阅读改为全屏沉浸分页：点中间显示工具栏，左右滑动或点边缘翻页；Android 上可选用音量键翻页，可调字号、行距和夜间模式。
- 修复分页漏字、页码挡住最后一行与长文卡顿；正文加载失败时自动重试最多 3 次。
- 列表划到底自动加载下一页；音量键翻页选项只出现在 Android，Windows 与 Linux 不再显示。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Full-screen paginated novel reader: tap the center for chrome; swipe or tap the edges to turn pages; on Android, optionally use the volume keys; adjust type size, line height, and night mode.
- Stops leaked page text and page numbers covering the last line, retries a failed novel-body load up to 3 times, and keeps only the current page mounted so long novels stay responsive.
- Feeds load the next page when you reach the bottom; the volume-key paging switch appears only on Android, not on Windows or Linux.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
