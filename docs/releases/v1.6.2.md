# PixNya 1.6.2

## 中文

- 小说阅读改为全屏沉浸分页：点中间显示工具栏，左右滑动或点边缘翻页，可调字号、行距和夜间模式。
- 修复分页漏字与正文加载重试；长文只渲染当前页，避免整篇分栏导致卡顿。
- 设置页与阅读页返回按钮统一为胶囊形状；关注列表的公开/非公开选项保持单行。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Replaced the novel reader with a full-screen paginated view: tap the center for chrome, swipe or tap the edges to turn pages, and adjust type size, line height, and night mode.
- Stops the next page from leaking into the current page, retries a failed novel-body load up to 3 times, and keeps only the current page mounted so long novels stay responsive.
- Capsule-shaped back controls on settings and reader screens; public/private follow chips stay on one line.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
