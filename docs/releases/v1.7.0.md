# PixNya 1.7.0

## 中文

- 更新为原创猫耳少女应用图标。
- 在线与离线小说统一使用沉浸分页阅读器，共享阅读进度、字号、行距、主题和 Android 音量键翻页设置。
- 新增个人书架，支持待读、在读、已读；首页展示最近在读，系列页面可继续上次阅读。
- 本地备份包含书架与阅读设置，兼容旧备份，并在合并时保留较新的阅读记录。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Introduced an original anime catgirl app icon.
- Unified online and offline novel reading with shared progress, pagination, typography, themes, and Android volume-key paging.
- Added a local bookshelf with to-read, reading, and finished states, recent reads, and series continuation.
- Included the bookshelf and reading preferences in local backups, with legacy backup support and preservation of newer reading records when merging.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
