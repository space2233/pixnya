# PixNya 1.4.4

## 中文

- 修复账号或列表上下文变化时收藏结果、批量操作和小说分页写回错误页面的问题。
- 媒体缓存增加内容完整性校验，等长损坏文件不再持续命中。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Fixed bookmark, batch-action, and novel-pagination results writing back to the wrong account or list after context changes.
- Added media-cache content integrity checks so same-size corruption is no longer served repeatedly.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
