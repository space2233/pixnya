# PixNya v0.28.2 私人测试版

这是 PixNya 源码仓库的第一次 GitHub 快照，同时提供 Windows x64 与 Android ARM64 的 Debug 测试附件。

> PixNya 是个人维护的非官方 Pixiv 客户端，与 pixiv Inc. 没有隶属、授权、认可或技术支持关系。请使用自己的账号，并遵守所在地法律、Pixiv 使用条款和作品版权要求。

## 本版内容

- 使用隔离 WebView 打开 Pixiv 官方登录页，应用本身不提供账号密码输入框；
- 支持标准、ECH 和低安全兼容直连三种连接方式，并明确提示低安全路线的中间人风险；
- 支持插画、漫画、小说、作者、搜索、排行榜、发现、关注、收藏、评论和独立回复页；
- 支持 Pixiv 评论表情、服务端贴图、本地屏蔽与仅本地保存的举报记录；
- 支持图片查看、Ugoira、下载队列、离线资料库、本机浏览历史和存储空间保护；
- 支持 R18 默认显示开关、登录会话恢复、返回位置恢复和移动端/平板安全区域；
- 包含自动更新基础设施，但本次 Debug 测试附件不进入正式自动更新通道。

## 0.28.2 修复

- 将诊断导出和许可证中的旧产品名统一为 PixNya；
- 修复桌面端缺少 updater 插件配置时启动即 panic、退出码为 101 的问题；

## 测试附件

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows x64 | `pixnya-0.28.2-windows-x64-debug.exe` | 便携 Debug EXE；需要系统 WebView2 Runtime；未做 Authenticode 签名，Windows 可能显示安全警告 |
| Android ARM64 | `pixnya-0.28.2-android-app-arm64-debug.apk` | Android 10/API 29 及以上；仅含 `arm64-v8a`；使用 Android Debug 证书签名 |
| 校验清单 | `SHA256SUMS.txt` | 只包含本次两个附件的 SHA-256 |

本次不提供 Linux 二进制，也不提供 ARM32 APK。ARM32 构建入口仅作为暂缓功能保留在源码中。

## 安全与安装说明

- 两个附件都是 **Debug 私人测试包，不是正式签名稳定版**。
- Debug 包包含完成 OAuth 兼容测试所需、可从程序中提取的客户端参数；只应存放在当前私人仓库并提供给受信任测试者。
- Windows EXE 未签名，不应绕过来源不明文件的系统警告；安装前请核对 SHA-256。
- Android APK 使用本机 Debug 证书签名。若设备上的旧包使用不同证书，需要先导出需要的数据再卸载旧包。
- 低安全兼容直连会降低 TLS 安全性，可能遭受中间人攻击；除标准/ECH 路线确实不可用外不建议启用。
- 本版不会静默安装更新；正式自动更新仍需要 Tauri updater 签名、Android 长期发布证书和签名更新清单。
