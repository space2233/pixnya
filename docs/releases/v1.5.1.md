# PixNya 1.5.1

## 中文

- 本版是维护/测试用 Draft 补丁；公开稳定版在 Publish 前仍为 `1.5.0`。
- 续期 Android 构建工具 OSV 与 RustSec 复核窗口。
- 进程内复用磁盘媒体缓存，并批量写入索引。
- 作品、小说、Ugoira 详情优先使用已有离线资料库文件。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- This is a maintenance/test Draft patch; public stable remains `1.5.0` until Publish.
- Renewed the Android build-tool OSV and RustSec advisory review windows.
- Reuses a process-resident media cache and batches index writes.
- Artwork, novel, and ugoira detail prefer existing offline-library files.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
