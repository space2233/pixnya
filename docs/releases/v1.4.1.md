# PixNya 1.4.1

## 中文

- 修复 ECH 模式缩略图加载及小说收藏状态同步问题，并补强返回状态、缓存恢复和本地备份回归。
- Android 构建期 Bouncy Castle 依赖升级到 `1.80.2`，消除已知 Critical 告警；APK runtime 继续保持零漏洞例外。
- 公开前要求完成 Windows x64 与 Android ARM64 活体验收；Windows ARM64、Linux x64 和 Android ARM32 本轮仅完成签名 CI 构建。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Fixed thumbnail loading in ECH mode and novel bookmark state synchronization, with stronger return-state, cache-recovery, and local-backup regressions.
- Updated the Android build-time Bouncy Castle dependencies to `1.80.2`, removing the known Critical advisory while keeping the APK runtime free of vulnerability exceptions.
- Publication requires live acceptance on Windows x64 and Android ARM64; Windows ARM64, Linux x64, and Android ARM32 receive signed CI builds only in this release.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
