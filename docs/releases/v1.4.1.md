# PixNya 1.4.1

## 中文

- 修复小说收藏状态在列表、详情与批量操作之间不同步的问题，并补强返回状态、缓存恢复和本地备份回归。
- Android 构建期 Bouncy Castle 依赖升级到 `1.80.2`，消除已知 Critical 告警；APK runtime 继续保持零漏洞例外。
- 本轮活体验收覆盖 Windows x64 与 Android ARM64；Windows ARM64、Linux x64 和 Android ARM32 仅完成签名 CI 构建。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Fixed novel bookmark state synchronization across lists, details, and batch actions, with stronger return-state, cache-recovery, and local-backup regressions.
- Updated the Android build-time Bouncy Castle dependencies to `1.80.2`, removing the known Critical advisory while keeping the APK runtime free of vulnerability exceptions.
- Live acceptance covers Windows x64 and Android ARM64; Windows ARM64, Linux x64, and Android ARM32 receive signed CI builds only in this release.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
