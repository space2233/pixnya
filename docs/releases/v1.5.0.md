# PixNya 1.5.0

## 中文

- 搜索记录支持更多容量档位、不限制、筛选和单条删除，并可随本地备份迁移。
- 作品与小说支持标题和简介搜索，类别与匹配方式可随 URL 分享和恢复。
- 浏览历史按批显示，减少长列表一次性挂载的图片和节点。
- 放大搜索框清除按钮，统一桌面与移动端操作尺寸。
- 头像和个人背景图优先显示热缓存；在线缓存保留一个总上限并优先保留高频缩略图。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Added larger and unlimited search-history limits, filtering, per-entry removal, and local-backup migration.
- Added title-and-description search for works and novels with shareable URL state.
- Renders browsing history progressively to avoid mounting every image and row at once.
- Enlarged search-field clear controls across desktop and mobile layouts.
- Reuses warm avatar and profile-background images while one total media-cache limit prioritizes frequently reused thumbnails.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
