# PixNya 1.4.3

## 中文

- 修复 ECH 模式缩略图加载、小说收藏状态同步及连接选择界面，并补强返回状态、缓存恢复和本地备份回归。
- 统一全应用字号，精简个人页和存储信息，并修复移动端诊断日志按钮布局。
- Android 构建期 Bouncy Castle 依赖升级到 `1.80.2`，消除已知 Critical 告警；APK runtime 继续保持零漏洞例外。
- 支持 Windows x64、Windows ARM64、Linux x64、Android ARM64、Android ARM32（Android 10+）。

## English

- Fixed ECH thumbnail loading, novel bookmark synchronization, and the connection picker UI, with stronger return-state, cache-recovery, and local-backup regressions.
- Unified typography across the app, simplified profile and storage information, and repaired the mobile diagnostic-log actions.
- Updated the Android build-time Bouncy Castle dependencies to `1.80.2`, removing the known Critical advisory while keeping the APK runtime free of vulnerability exceptions.
- Supports Windows x64, Windows ARM64, Linux x64, Android ARM64, and Android ARM32 (Android 10+).
