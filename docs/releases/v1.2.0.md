# PixNya 1.2.0

## 中文

- 首次启动新增连接方式选择，并统一标准、ECH 与兼容模式设置。
- 精简设置界面，在线媒体缓存新增 5 GiB、10 GiB 与不限制选项。
- 改进连接安全、会话切换和导出任务的稳定性。
- 支持 Windows x64、Linux x64、Android ARM64（Android 10+）。

## English

- Added first-run connection setup with one global Standard, ECH, or Compatible mode.
- Simplified Settings and added 5 GiB, 10 GiB, and unlimited media-cache options.
- Improved connection security, session switching, and export-task reliability.
- Supports Windows x64, Linux x64, and Android ARM64 (Android 10+).
