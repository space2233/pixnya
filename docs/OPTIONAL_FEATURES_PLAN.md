# 备选功能计划

> 状态：暂停，不属于当前开发路线
> 日期：2026-08-03
> 说明：当前唯一活跃功能为自动检查更新与自动更新；本文件中的项目不计入“尚未完成”的当前任务，也没有排期。

## 1. 收录规则

- 只有在自动更新完成后，才从本文件重新激活项目。
- 每次最多重新激活一个主题，并先补充独立需求、风险和验收标准。
- 不因为上游接口“看起来存在”就承诺功能；账号写操作必须先确认授权、安全和可维护性。
- 已经完成的小说、评论、作品/小说系列、本地标签收藏夹、历史、下载队列和离线资料库不再列为备选。

## 2. 账号与社区功能

### 多账号切换

- 为每个账号隔离 refresh token、安全存储键、缓存归属、下载归属和浏览设置。
- 切换账号必须取消旧账号的在途写操作，不能让收藏或关注写入错误账号。

### 更完整的站内通知

- 仅在确认存在稳定且可授权的数据来源后实施。
- 当前通知页继续明确说明不提供伪造或演示通知。

### 评论管理

- 评论删除、更多回复管理和错误恢复。
- 必须确认写操作幂等性、账号归属和审核失败提示。

### 投稿、私信与直播

- 保持低优先级；单独进行条款、账号安全、上传内容和滥用风险评审。
- 不与普通浏览功能共享宽泛权限。

## 3. 媒体与阅读增强

### Ugoira/GIF/APNG/WebM 导出

- 明确帧率、色彩、音频、内存与磁盘预算。
- 导出必须是可取消的后台任务，不能阻塞播放和下载队列。

### 更高级的本地整理

- 跨收藏夹批量操作、保存筛选器、批量标签和重复内容检测。
- 继续保持完全本机，不引入项目方云端账号。

### 云同步

- 默认不做；若未来启用，必须先决定端到端加密、冲突合并和密钥恢复。
- 不上传 Pixiv token、Cookie 或官方登录页面数据。

## 4. 平台与架构扩展

- Windows ARM64。
- Linux ARM64。
- Android `x86_64` 模拟器发布包。
- Android universal APK 与恢复 ARMv7 Release；首个稳定版只发布 ARM64，ARMv7 手动调试入口继续保留。
- iOS 与 macOS；需要独立评估 WebView、签名、分发和商店规则。
- 更多 Linux 包格式；首个稳定版的自动更新只以 AppImage 为应用内安装路线。

## 5. 网络与登录实验

- 允许用户自定义可信 DoH，但必须防止远端配置扩大低安全域名白名单。
- 自带浏览器内核以强制并观测登录页 ECH；先评估安装体积、安全更新负担和 Android 可行性。
- 正式版 refresh token 导入入口；默认仍只保留开发诊断用途。
- 兼容 IP 配置的可验证远端更新；签名配置只能收窄/替换地址，不能远程关闭更多证书验证。

## 6. 暂停的验证与发布工作

以下不是产品功能，但按当前决定一并暂停，未来公开发布前仍需重新纳入发布闸门：

- Linux WebKitGTK 实机启动、登录窗口和自动更新活体测试。
- 标准、ECH、兼容三条路线的真实测试账号低频闭环。
- Android ARMv7 真实 32 位设备核心流程冒烟测试。
- Windows/Linux 新架构与更多安装包矩阵。
- 按最终二进制精确裁剪的逐平台 SBOM 和外部测试用户门户（当前正式流水线已提供完整锁图 SPDX SBOM、许可证清单与自动正文归档）。

## 7. 明确不做

- 内置公共代理、VPN 或项目方运营的流量中转。
- 绕过 Pixiv 付费、年龄、地区或账号权限控制。
- 自动批量抓取整个关注列表或作者全部作品。
- 伪造站内通知、账号统计或不存在的上游数据。
- 默认收集遥测、上传浏览历史或把登录凭据交给项目服务器。
