# PixNya 1.1.0 功能范围

> 当前源码版本：`1.1.0`
> 状态：本次功能版本的四组范围均已实现，等待完整发布验证与真实测试账号低频验收
> 版本规则：Bug 修复增加第三位；新增功能增加第二位；不兼容迁移才增加第一位
> 发布口径：这些功能合并进入同一次 `1.1.0` 升级，不预占 `1.2.0`–`1.4.0` 版本号

## 1.1.0：只读通知与评论管理

- 通知页接入列表、分组展开和 `next_url` 分页，只发送 GET；不注册推送、不修改通知设置、不写回已读状态、不后台轮询。
- 通知正文按纯文本渲染；媒体沿用安全代理。作品、小说和用户链接在应用内打开，其他链接仅允许 `https://www.pixiv.net` 并交给系统浏览器。
- 插画和小说评论仅对本人评论显示删除入口；确认成功后才从界面移除，失败保留并允许重试。
- 评论编辑器接入官方贴图目录，支持文字、单个贴图或二者组合；原有回复分页和文字表情继续保留。
- Rust/TypeScript 类型、API 数据源、Tauri 命令和前端回归已覆盖通知、贴图及评论删除。

## 1.1.0-B：Ugoira 导出

- Windows 和 Linux 上的在线或已下载 Ugoira 可导出 GIF、APNG 和 WebM；Android 不捆绑外部编码器，当前不显示导出入口。
- 导出使用可取消后台任务，展示阶段、进度、目标路径和失败原因，不阻塞播放器或下载队列。
- 开始前检查可用磁盘空间、帧数、分辨率、总时长和估算解码内存；失败或取消会清理任务临时目录和不完整输出。
- 严格使用原始帧延时，不插帧；WebM 明确无音频。编码条件不可用时返回明确失败。
- 编码器边界为本机受信任的 `ffmpeg`/`ffprobe`；可通过 `PIXNYA_FFMPEG_PATH` 和 `PIXNYA_FFPROBE_PATH` 指定路径。

## 1.1.0-C：官方屏蔽与静音

- 接入 access-block 列表、分页、添加和解除屏蔽。
- 接入 mute 的用户/标签列表及增删操作。
- 官方账号状态与“仅本机隐藏/本地报告”分区显示，绝不自动互相转换。
- 所有账号级写操作要求确认、串行提交和失败恢复；登录账号变化后拒绝旧会话结果写回界面。
- 不扩展到评论举报、个人资料编辑、投稿或通知设置。

## 1.1.0-D：高级本地整理

- 支持跨收藏夹批量移动、批量添加/移除本地标签和批量删除本地记录；只修改标签时默认保留原收藏夹。
- 支持保存本地筛选条件，并按类型、标签、收藏夹、保存时间和空间占用组合查询。
- 通过 Pixiv 资源 ID，以及内容类型加文件 SHA-256 检测重复内容；默认且目前仅报告，不自动删除。
- SQLite 元数据批量变更使用事务；文件批量删除先进入本机隔离区，任一步失败会回滚已有移动。
- 功能完全本机，不引入云同步、项目账号或服务器端批量操作。

## 测试与发布边界

- 自动化覆盖通知分页与链接安全、评论归属与删除恢复、贴图组合发表、Ugoira 任务/限制/取消清理、屏蔽与静音串行写入、本地批量事务、保存筛选器和重复报告。
- 发布前仍需使用测试账号低频验证通知 GET、评论写接口、屏蔽/静音接口，以及用实际不同帧率/分辨率作品验证三种 Ugoira 格式。
- 每个版本运行完整前端检查、Node 回归、Rust workspace 测试、格式和 Clippy；正式产物构建 Windows x64/ARM64、Linux x64、Android ARM64/ARM32。
- 投稿、个人资料编辑和通知写操作不做。多账号、新平台、私信、直播与云同步保留在[无排期备选计划](OPTIONAL_FEATURES_PLAN.md)。
