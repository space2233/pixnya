# PixNya 当前功能与维护路线

> 当前公开稳定版：`1.5.0`
> 当前源码版本：`1.5.0`
> 当前维护范围：`1.5.1`（补丁，无新功能）
> 版本规则：Bug、安全与兼容修复增加第三位；新增功能增加第二位；不兼容迁移才增加第一位

## 已交付功能

- 只读站内通知、评论删除、回复分页和官方贴图评论。
- Ugoira 播放；Windows/Linux 可使用本机 `ffmpeg` 导出 GIF、APNG 和 WebM。
- 官方 access-block、用户静音和标签静音，与本地隐藏/报告明确分区。
- 本地收藏夹、标签、组合筛选、批量整理、重复内容报告和离线资料库。
- 插画与小说官方收藏标签筛选，以及公开性、标签和取消收藏的批量管理。
- 凭据无关的本地数据备份与迁移，可选离线内容，支持合并、替换和崩溃回滚。
- Windows x64/ARM64、Linux x64、Android ARM64/ARM32 的签名 Release 与自动更新。

## 1.4.3 已交付维护内容

- 修复严格 ECH 模式下 Pixiv 图片 CDN 白名单遗漏造成的缩略图失败。
- 统一首次连接选择与设置页视觉，修复未定义主题变量造成的不可见控件。
- 修复小说收藏状态在列表、详情和批量操作之间不同步的问题。
- 补强返回状态、缓存重启/损坏恢复和备份离线目录事务回归。
- 将 Android 构建期 Bouncy Castle 依赖成组升级到 `1.80.2`，消除 Critical 告警并重建供应链证据。
- 统一字号阶梯，精简个人页登录状态，将空间信息迁入存储设置，并修复手机日志操作布局。
- 已在 Windows x64 与 Android ARM64 完成从公开 `1.4.0` 覆盖升级、数据保留、三种连接模式和备份恢复验收。
- Linux x64、Windows ARM64 与 Android ARM32 继续要求 CI 签名构建成功；未完成本轮活体验收时必须在发布记录中说明。

## 1.4.4 已交付维护内容

`1.4.4` 维护工作已完成并打 tag，但从未作为面向用户的 GitHub Release 公开；内容已包含在公开稳定版 `1.5.0` 中。

- 修复异步收藏结果未绑定发起账号和资源的问题，账号切换、退出或清除数据后不再保留旧覆盖状态。
- 修复小说下一页和批量结果跨栏目、筛选或账号写回当前列表的问题。
- 为媒体缓存记录内容 SHA-256，拒绝等长损坏文件持续命中。
- 补齐字号 shorthand 门禁并同步已实施的发布治理状态；该维护版不增加新功能。

## 1.5.0 已交付

- 搜索记录支持 8、20、50、100 条及不限制、内联筛选和单条删除，并随本地备份迁移；不限制仍受 WebView 本机存储配额约束。
- 作品与小说可选“标题与简介”搜索；类别和匹配方式写入 URL，刷新、分享和返回保持一致。
- 浏览历史保持现有 500 条本地数据边界，但按 48 条渐进挂载，降低长列表 DOM 与图片解码压力。
- 统一放大桌面与移动端搜索框清除按钮，补齐浏览历史筛选框。
- 头像和个人背景图优先复用安全域隔离的热缓存，页面往返时立即显示并在后台刷新。
- 在线缓存共用一个总上限；旧原图缓存自动清理，预览图先于缩略图淘汰，设置页显示分类占用。

## 1.5.1 维护范围

`1.5.1` 是当前激活的补丁范围，不是 `1.6.0`。公开稳定版与源码版本在本轮签名 Draft 前仍为 `1.5.0`。本轮不增加新功能、新平台或新的缓存接口。

- 复核并续期 Android 构建工具 OSV 限期例外，使发布闸门在原 2026-09-08 及后续到期日后仍保持精确、限 scope、限版本、限期；runtime 继续零例外。
- 复核仍被 Tauri 2.11.5 锁图挡住的 RustSec 临时例外；不升级 Tauri、不放开全局 ignore。
- 进程内复用磁盘媒体缓存：缩略图/预览命中不再每次 `MediaCache::open`，也不再每次更新 LRU 就写 `index.json`；打开时仍按 1.5.0 策略清除原图缓存，读时仍校验 SHA-256。
- 作品、小说、Ugoira 详情在本地已有对应离线文件时优先使用离线资料库字节；缺失或完整性失败则回退到现有缓存/网络路径。离线资料库与媒体缓存目录保持分离。
- 在 Windows x64 与 Android ARM64 上，从公开 `1.5.0` 做覆盖升级活体验收；Android 须覆盖标准、ECH、兼容三种连接模式。
- Linux x64、Windows ARM64 与 Android ARM32 继续只要 CI 签名构建成功；本轮不宣称这些平台的活体验收。
- 活体验收结果未跑之前，不得填写 PASS/失败、设备名、安装包 SHA-256 或工作流 run ID。

## 后续边界

- 投稿、个人资料编辑和通知写操作不做。
- 多账号、新平台、私信、直播、云同步和网络实验继续保留在[无排期备选计划](OPTIONAL_FEATURES_PLAN.md)。
- 每次只激活一个明确的版本范围；当前激活的是 `1.5.1` 维护补丁。`1.6.0` 主题在本轮之后再单独决定，不顺带扩展账号、平台或新的缓存接口。
